# RustDesk SX 2.1.1 — direct-only mode and Linux shutdown guard

Linux Release build with Flutter 3.47.9 / Dart 3.13.7 and Rust 1.99.1.
The application, Debian package and v2.1.1 tag use the same product version;
Flutter build number advances to 70. Upstream baseline remains RustDesk 1.5.0.

## Changes

- Explicit opt-in direct-only mode keeps Tailscale/IP and host:port connections
  without ID registration, NAT/ID probes or public ID/relay fallback.
- Existing direct devices receive bounded direct-port presence checks and clear
  reachability labels. Port reachability is not authenticated remote control.
- Linux main-engine shutdown awaits main event-stream removal; investigation
  found an online-query callback still posting during shutdown.
- Verification-code entry keeps focus/caret while the underlying dialog rebuilds.
- Preserve MiSans/Chinese UI, native Wayland, text clipboard/CJK input helpers,
  hardware-codec paths, multi-display optimizations and optional DRM/DRM-wake.

See the [incident record](../incidents/2026-10-30-local-direct-only-and-shutdown.md)
for the 16 Flutter / 1 Rust configuration regression tests and the exact limits of
the single normal-close runtime check. Native Flutter teardown warnings remain;
active-session shutdown stress and a new complete remote-session acceptance are
not claimed for this package. Continuous 4K60 remains an optimization goal.

## Packages and compatibility

The .deb and portable archive target Ubuntu 26.04 x86_64, glibc >= 2.43 and system
FFmpeg 8. They are not Ubuntu 24.04 packages. Windows/macOS/ARM are not included.
Use BUILD-INFO.json for exact source, SDK/framework/engine/Dart versions, features,
core hash, dependencies and pinned libdrmtap source/hash; use SHA256SUMS for assets.
The core ships optimized and stripped, with private debugging symbols retained
only on the build host. Flutter, MiSans and libdrmtap licenses remain included.

libdrmtap is built from the build.py pinned revision with EGL enabled and its
separate privileged helper disabled. The package retains optional root-owned
service definitions; installation does not enable/restart services automatically.
No user home/config, credentials, restore tokens or peer records are packaged.

## Upgrade and configuration

```sh
sudo apt install ./rustdesk-sx_2.1.1_amd64.deb
```

Back up current configuration before any installed-program upgrade. Existing
account, passwords, peers, direct access, service overrides and Portal choices
are retained; this package does not force direct-only mode on existing users.
For Tailscale/IP-only deployments, quit the app and add `direct-only = 'Y'` to
its existing RustDesk2.toml [options], then restart. Keep direct-server enabled
where incoming direct sessions are required. Do not replace the whole options
section or use stop-service to suppress ID registration.

The fixed root library path and service opt-in/rollback remain as documented in
[the unattended package notes](2026-10-26-unattended-linux-preview.md).
Do not enable a second conflicting remote listener. No automatic system unlock
or password change is provided.

## Rollback

The previous v2.1.0 assets remain available. Use a previous package/portable tree
and restore only configuration keys required by the old binary, retaining newer
account/peer changes. In particular, old binaries ignore direct-only: restore
the previous ID-server configuration before returning to them. If rolling back
a service-enabled installation, restore its previous executable/library/service
paths as a unit rather than leaving a service pointed at removed files.
